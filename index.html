§1

What is the agentic economy?

An AI agent is software that doesn’t just answer — it acts on someone’s behalf. Brian Armstrong’s argument in 2024 was simple: agents are held back because they can’t pay for anything, and crypto wallets give them a way to transact.[2]

That idea moved fast. Coinbase’s x402 protocol lets an agent pay for data, compute or another AI’s services in stablecoins, straight over the web — no account, no API key, no prepaid credits.[8]

The next generation of agents won’t just advise — they’ll act.Erik Reppel & Josh Nickerson, Coinbase — Cointelegraph, Feb 2026

The card networks followed. Mastercard requires agents to be verified before they pay; Visa gives developers tokenized cards and spending controls for agents.[7] Google’s AP2 goes after the hard questions: did the user approve this purchase, can the merchant trust the request, and who is responsible if it goes wrong.[11]

Big money is betting on it. McKinsey forecasts agentic commerce could reach $3–5 trillion globally by 2030.[25] Visa says AI-driven traffic to US retail sites rose more than 4,700% in a year.[28] Stripe paid $1.1B for Bridge; Mastercard agreed to pay up to $1.8B for stablecoin firm BVNK.[4][29]

And it’s reaching ordinary accounts. Since May 2026, Robinhood customers can hand an agent its own trading account and credit card — more than 150,000 opened one in four months.[17][18] Coinbase followed with an account AI assistants can trade from directly.[22]

Put together, it’s a new layer of the economy: agents that can talk to tools and to each other, prove who they are, and move money. The stack below breaks it down.

§3

How an agent pays

x402, step by step
AGENTSERVER
01
Request

The agent asks for something — an API, a dataset, a page.

02
402 Payment Required

Instead of the content, the server replies with payment instructions.

03
Payment authorization

The agent pays — in stablecoins, settled near-instantly.

04
Access + confirmation

Once the payment is verified, the agent gets what it asked for.[12]

That’s the whole loop. No account, no subscription, no API key. x402 reuses HTTP’s “402 Payment Required” code — long unused — so payment becomes part of an ordinary web request.[8][12]

The examples given at the x402 Foundation launch: an AI assistant buying from several merchants at once, agents paying per browser session, trading bots buying real-time data through micropayments.[12] By February 2026 x402 had reportedly processed 50 million transactions.[15]

§4

Agents at work

What they can do today
May 27, 2026

Robinhood

A trading account and a credit card, just for your agent.

“Our mission has always been to democratize finance for all, and now, that mission extends to AI agents.”Vlad Tenev, Robinhood CEO — May 2026
How it works
Agents plug in through Robinhood’s Trading and Banking MCP servers. They trade from a separate account holding only what you put in it, and shop with a virtual Gold Card.[17]
Guardrails
Spending limits, optional approval for every purchase, a push notification per trade, and an instant disconnect. Agents can’t see your main card number.[17]
Fine print
Robinhood doesn’t control or audit third-party agents, and customers carry the risk of agent-placed orders.[17]
Since
By late September, over 150,000 customers had opened agentic accounts and agents were using Robinhood’s tools almost 30 million times a day. Robinhood is now building its own in-app agents.[18]
Jun 11, 2026

Coinbase for Agents

An account your AI assistant can trade and pay from.

How it works
Works inside ChatGPT or Claude via Coinbase’s MCP server. Ask it to rebalance a portfolio, run an investment thesis or advise on a single trade.[22]
Payments
Pays for research data, APIs and compute with x402 — no login, no subscription. USDC settles most transactions.[22][23]
Guardrails
Run it in a sandbox or on your main account up to a spending cap. Autonomy ranges from one recommendation to a standing thesis the agent runs itself.[23]
Markets
Crypto spot and derivatives at launch; equities and prediction markets planned.[22]
Sep 29, 2025

ChatGPT Instant Checkout

Buying things without leaving the chat.

How it works
US ChatGPT users can buy from Etsy sellers in the chat, with more than a million Shopify merchants to follow. Built on the Agentic Commerce Protocol, co-developed with Stripe.[13]
Guardrails
Payment tokens are scoped to one merchant and one cart total, so the agent never handles stored card details. Orders stay in the merchant’s own systems.[13]
Reach
ChatGPT had 700 million weekly users at launch.[13] PayPal has since rolled out tools so its merchants can sell on AI surfaces too.[30]
Mar 18, 2026

Tempo + MPP

A payments blockchain with a protocol for machines.

What it is
A blockchain from Stripe and Paradigm built for high-volume, low-cost stablecoin payments. It launched with the Machine Payments Protocol, an open standard for agents and services to request, authorize and settle payments.[20][21]
Sessions
An agent reserves funds upfront, then pays as it goes while using a service. Many small payments are batched into one settlement.[20]
Reach
100+ services in its directory at launch. Design partners include Anthropic, DoorDash, Mastercard, OpenAI, Shopify and Visa. Visa, Stripe and Lightspark extended MPP to cards and Bitcoin’s Lightning Network.[20]
Oct 2024

Virtuals Protocol

Agents with their own tokens.

How it works
Anyone can create an AI agent and tokenize it. Each agent’s token trades paired with $VIRTUAL.[26][27]
Luna
The flagship agent: livestreams 24/7, holds her own wallet, and sent $LUNA to users who listed Base wallets in their X bios.[26][27]
First 3 weeks
1,000+ agents created, 17,500 token holders and over $250M in trading volume.[27]

§7

Open questions

What isn’t solved yet

  1. Who approved it?

    If an agent buys the wrong thing, who pays? Google built AP2 around three questions: did the user approve this purchase, can the merchant trust the request reflects what the user wanted, and who is responsible for fraud or mistakes.[11]

  2. How autonomous is “autonomous”?

    Truth Terminal, the bot that got $50K from Marc Andreessen, had limited autonomy: its human handler approved its posts and decided who it talked to.[1]

  3. Can agents be tricked?

    AI jailbreaker Pliny the Prompter tried to get Truth Terminal to send him the funds. Its creator rejected the attempt and the bot refused.[1]

  4. Who holds the keys?

    The answers so far are limits set in advance. ChatGPT’s checkout uses payment tokens scoped to one merchant and one cart total, so the agent never touches stored card details.[13] Coinbase’s Agentic Wallets let users set permissions before the agent acts.[15]

  5. Who checks the agents?

    ERC-8004 proposes independent validators who stake to check an agent’s claims — rewarded if right, slashed if wrong. It is still under review.[10] Mastercard requires agents to be verified before they can pay.[7] Visa’s Trusted Agent Protocol, built with Cloudflare, lets merchants tell approved agents from malicious bots: “We believe the entire payments ecosystem has a responsibility to ensure sellers can trust AI agents.”[28]

  6. Whose rails win?

    x402, AP2, the Agentic Commerce Protocol, Visa and Mastercard all launched in 2025. Several are designed to stay open: AP2 is payment-agnostic, ACP is meant to work with multiple processors, and x402 plans to support cards and bank accounts.[11][13][12]

  7. Who’s liable when it goes wrong?

    For now, mostly you. Robinhood’s terms: “You assume all risk for trades executed by AI agents and for any use of your data by third-party LLM providers.” Fed Governor Christopher Waller has named authentication, liability and fraud as barriers to agents handling consumer payments.[19]

  8. Who regulates it?

    FINRA’s 2026 oversight report covers AI agents for the first time but adds no new rules, calling existing ones “technologically neutral”.[19] The Financial Stability Board has proposed non-binding practices, warning that undoing an agent’s actions “can be difficult or impossible for humans.”[33]

Glossary

MCPProtocol
Model Context Protocol. Anthropic’s standard for giving AI agents tools and context.[5]
A2AProtocol
Agent2Agent. Google’s protocol for agents to discover each other and delegate tasks.[6]
x402Payments
Uses the web’s old “402 Payment Required” code so sites and agents can settle payments in stablecoins — no accounts or API keys.[8]
AP2Payments
Agent Payments Protocol. Google’s standard for proving an agent has a user’s authority to buy something.[11]
ACPPayments
Agentic Commerce Protocol. OpenAI and Stripe’s standard behind checkout inside ChatGPT.[13]
ERC-8004Standard
“Trustless Agents.” Ethereum registries for an agent’s identity, reputation and validation.[10]
HTTP 402Web
A web status code meaning “Payment Required”. Barely used until x402 gave it a job.[12]
Shared Payment TokenPayments
A token scoped to one merchant and one cart total, so an agent can pay without seeing card details.[13]
AgentKitWallets
Coinbase’s framework for building wallets into AI agents.[15]
AP4MPayments
Agent Pay for Machines. Mastercard’s service for small, continuous payments between agents.[16]
MPPPayments
Machine Payments Protocol. Tempo and Stripe’s open standard for agents and services to request, authorize and settle payments.[20]
SessionPayments
In MPP, funds an agent reserves upfront and spends as it uses a service, settled in one batch.[20]
TAPTrust
Trusted Agent Protocol. Visa’s framework for merchants to recognise approved agents using cryptographic signatures.[28]
IAOTokens
A token launched alongside a new AI agent on Virtuals Protocol.[26]
Agentic accountBrokerage
On Robinhood, a separate account an agent trades from, holding only what you deposit.[17]

The FSB’s suggestion that firms govern AI agents with HR-style controls, like staff.[33]
